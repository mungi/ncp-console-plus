# NCP Console Plus

Naver Cloud Console의 **서버 접속 콘솔(VNC)** 을 전체 화면으로 보고 접속 시간을 자동으로 연장하며, 콘솔 탭에 **서비스 이름과 리전 아이콘**을 표시하는 Chrome 확장 프로그램입니다.

## 지원 콘솔

- 민간 클라우드: `*.ncloud.com` (`console.ncloud.com` 등. Neuro처럼 서비스에 따라 콘솔 서브도메인이 달라지는 경우 포함)
- 금융 클라우드: `console.fin-ncloud.com`
- 공공 클라우드: `console.gov-ncloud.com`

`https` 주소만 해당합니다.

## 설치 방법

1. Chrome 브라우저에서 `chrome://extensions/` 주소로 이동합니다.
2. 오른쪽 상단의 "개발자 모드"를 활성화합니다.
3. "압축해제된 확장 프로그램을 로드합니다." 버튼을 클릭합니다.
4. 이 확장 프로그램 폴더(`extention`, `manifest.json`이 있는 폴더)를 선택합니다.
5. 이미 열려 있던 콘솔 탭은 새로고침해야 확장이 적용됩니다.

## 사용 방법

- **콘솔 위 버튼**: 서버 목록에서 "서버 접속 콘솔"을 열면 "연장" 버튼 왼쪽에 아이콘 버튼 2개와 `자동연장` 토글 스위치가 나타납니다. 버튼에 마우스를 올리면 설명이 보이고, 켜진 버튼은 빨간색으로 바뀝니다.
  - **네 모서리 아이콘 (전체화면)**: 브라우저 Fullscreen API로 콘솔이 모니터 전체를 덮습니다. 실패하면 창 전체화면으로 대신 표시합니다. Esc 또는 같은 버튼으로 끕니다.
  - **창 아이콘 (브라우저 창 전체화면)**: 탭과 주소창은 그대로 두고, 페이지 영역 전체를 콘솔로 채웁니다. 오른쪽 위에 `남은 접속 시간: 04:43 (전체 연결 시간: 00:17)` 표시와 반투명 종료 버튼이 나타나며, 종료 버튼으로 끕니다. (시간은 콘솔이 표시하는 값과 같고 1초마다 갱신됩니다.) 콘솔 화면을 클릭한 뒤에는 Esc가 서버(VM)로 전달되므로, 이때는 이 종료 버튼을 사용하세요.
  - 한쪽 전체화면이 켜진 상태에서 다른 버튼을 누르면 그 방식으로 바로 바뀝니다.
  - **자동연장 토글**: 스위치를 클릭해 켜고 끕니다. 켜지면 초록색에 손잡이가 오른쪽, 꺼지면 회색에 손잡이가 왼쪽입니다.
  - **종 아이콘 (20분 종료 예고)**: 클릭해 켜고 끕니다. 켜지면 초록색, 꺼지면 회색에 사선이 그어집니다. 기본은 켜짐입니다.
    - 켜져 있으면 전체 연결 시간 20분 강제 종료 2분 전부터 화면 위쪽 가운데에 남은 시간 알림이 뜹니다. 주황색이었다가 마지막 1분에는 빨간색으로 바뀝니다.
    - 모니터 전체화면이나 창 전체화면 중에도 보이며, × 버튼으로 닫을 수 있습니다.
- **확장 아이콘 팝업**: 기능 2가지를 켜고 끌 수 있습니다. 설정은 열려 있는 콘솔 탭에 바로 적용되고, 새로고침해도 유지됩니다.
  - **탭 이름을 서비스명으로 변경**: 끄면 탭 제목과 아이콘이 콘솔 원래 모습으로 돌아갑니다.
  - **서버 접속 콘솔 추가 기능**: 끄면 콘솔 위에 추가된 UI(전체화면 버튼 2개, 자동연장 스위치, 종 아이콘)가 모두 사라지고 원래 "연장" 버튼만 남습니다. 자동 연장과 20분 종료 예고도 멈추고, 켜져 있던 전체화면도 해제됩니다. 다시 켜면 자동연장·종료 예고는 이전 설정으로 돌아옵니다.

## 자동 연장 동작

- 콘솔 세션은 "연장"할 때마다 5분이 다시 주어집니다.
- 자동 연장이 켜져 있으면 다음 중 하나에 해당할 때 "연장" 버튼을 대신 누릅니다.
  - 표시된 남은 시간이 60초 이하일 때
  - 마지막 연장 뒤 실제 시간으로 3분 45초가 지났을 때 (백그라운드 탭에서는 화면 타이머가 실제보다 느리게 흐르기 때문)
- 시간 점검은 15초마다 합니다. 가장 늦어도 마지막 연장 뒤 4분, 즉 만료 1분 전에는 연장됩니다.
- 같은 연장을 여러 번 누르지 않도록, 한 번 누른 뒤 10초 동안은 다시 누르지 않습니다.
- **전체 연결 시간은 최대 20분입니다.** 콘솔 화면은 자체 카운터가 20:00이 되면 세션을 닫고, 서버도 한도를 넘긴 연장 요청을 거부합니다(오류 24342). 이 확장으로 늘릴 수 없습니다.
- 화면의 전체 연결 시간은 1초씩 세는 페이지 타이머라 백그라운드 탭에서 느려집니다. 확장은 세션 시작 시각을 기억해 실제 경과 시간을 계산하고, 화면 값과 실제 값 중 큰 쪽이 20분에 도달하면 자동 연장을 멈춥니다.
- 설정은 `chrome.storage.sync`에 저장되어 새로고침한 뒤에도 유지됩니다.

## 탭 이름과 리전 아이콘

- **탭 제목**: `화면 이름 - 서비스명` 형태로 바뀝니다. 둘이 같으면 하나만 표시합니다.
  - 예: `/vpc-network/subnet` → `Subnet Management - VPC`, `/vpcCloudPostgresql/monitoring` → `Monitoring - CDB PostgreSQL`, `/vpc-compute/server` → `Server`
  - 화면 이름과 서비스명은 고정된 규칙표 없이 콘솔 자체 정보에서 가져옵니다.
    - 화면 이름: 왼쪽 메뉴에서 선택된 항목 이름
    - 서비스명: 콘솔 메뉴 데이터(`__CONSOLE_NUXT_DATA__`)에서 경로가 가장 길게 일치하는 서비스명. 그것도 없으면 첫 경로가 같은 서비스명
  - 긴 서비스명은 축약합니다: `Cloud DB for X` → `CDB X`, 그 밖에 SENS, NKS, NCR, DMS, KMS, GTM 등. 끝에 붙은 `Update`, `(Deprecated)` 표시는 뺍니다. 축약표는 `js/content.js`의 `SERVICE_ABBR`에 있습니다.
  - 페이지를 새로 불러오지 않는 화면 이동(SPA)도 화면 변경을 감지해서 반영합니다.
- **탭 아이콘(파비콘)**: 콘솔 상단에서 선택된 리전의 아이콘(국기, 또는 Private Cloud 등 전용 아이콘)으로 바뀝니다.
- **NCP Tab Renamer 같은 다른 탭 이름 확장과 함께 쓰지 마세요.** 서로 제목을 덮어쓰게 됩니다. 이 확장은 10초 안에 제목을 10번 넘게 다시 바꿔야 하면 잠시 멈추지만, 다른 확장은 끄는 것이 좋습니다.

## 저장소 구성

- `extention/` : 확장 프로그램 본체 (Chrome 에서 "압축해제된 확장 프로그램 로드"로 선택하는 폴더)
- `site/` : GitHub Pages 소개 사이트 (소개, 개인정보처리방침, 이용 안내, 지원). `.github/workflows/pages.yml` 이 배포합니다.
- `docs/` : Chrome 웹 스토어 등록용 문서 (일반 텍스트). 등록 정보, 개인정보 보호 답변, 제출 체크리스트
