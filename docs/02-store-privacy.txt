Chrome 웹 스토어 "개인정보 보호" 탭 답변 (한국어)

1. 단일 목적
네이버 클라우드 플랫폼 콘솔 사용을 편하게 하는 것입니다. 탭 제목·아이콘 표시, 서버 접속 콘솔의 전체화면 버튼, 세션 자동 연장, 종료 예고를 제공합니다.

2. 권한 사유
storage
기능 켜짐/꺼짐 설정과 탭 제목 기록(화면 경로와 제목, 최대 300개)을 저장합니다. 외부로 전송하지 않습니다.

호스트 권한 (https://*.ncloud.com/*, https://console.fin-ncloud.com/*, https://console.gov-ncloud.com/*)
네이버 클라우드 콘솔에서만 동작합니다. 메뉴·서비스 이름과 리전 아이콘을 읽어 탭 제목과 아이콘을 바꾸고, 서버 접속 콘솔의 시간 표시와 "연장" 버튼을 읽어 전체화면 버튼, 자동 연장, 종료 예고를 제공합니다. 서비스마다 콘솔 서브도메인이 달라(예: Neuro) *.ncloud.com 이 필요합니다.

3. 원격 코드
사용하지 않음. 모든 코드가 패키지에 포함되어 있습니다.

4. 데이터 사용
수집하는 데이터 유형은 모두 체크하지 않습니다. 저장하는 것은 설정값과 "화면 경로 + 탭 제목" 기록뿐이며 이 기기에만 있습니다. 대시보드가 이 기록을 "웹 기록"으로 보라고 하면 체크하고 위 설명을 적어 주세요.

5. 인증
3개 항목(제3자 판매·전송 금지, 단일 목적 외 사용 금지, 대출 목적 사용 금지) 모두 체크합니다. 사용자 데이터를 전송하지 않으므로 모두 사실입니다.

6. 개인정보처리방침 URL
https://mungi.github.io/ncp-console-plus/privacy.html

7. 심사자용 안내
계정 로그인이 필요한 콘솔에서만 동작해 직접 확인이 어렵습니다. 아래 내용을 입력하세요.
▼
네이버 클라우드 콘솔(console.ncloud.com 등)에서만 동작하며 로그인이 필요합니다.
1. 콘솔 화면을 열면 탭 제목과 아이콘이 바뀝니다. (예: /vpc-network/subnet -> "Subnet Management - VPC")
2. "서버 접속 콘솔"을 열면 "연장" 버튼 옆에 전체화면 버튼 2개, 자동연장 스위치, 종 아이콘이 나타납니다.
3. 확장 아이콘의 스위치로 두 기능을 켜고 끌 수 있고, 끄면 추가 요소가 모두 사라집니다.
네트워크 요청과 원격 코드가 없습니다. 소스: https://github.com/mungi/ncp-console-plus
