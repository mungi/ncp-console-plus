NCP Console Plus · 시행일 2026-11-09

요약: NCP Console Plus는 개인이 무상으로 만든 비공식 확장 프로그램입니다. NAVER Cloud와 무관하며, 현재 상태 그대로 제공되고, 사용에 따른 책임은 사용자에게 있습니다.

1. 성격

  • 이 확장 프로그램은 개인이 개발해 무상으로 제공하며, NAVER Cloud Corp. 또는 그 계열사가 만들거나 보증·후원한 것이 아닙니다.
  • NAVER, Ncloud, NAVER Cloud Platform 및 관련 이름과 로고는 각 권리자의 상표입니다. 이 사이트와 확장 프로그램은 식별과 설명을 위해서만 이름을 언급합니다.
  • 이 사이트의 화면 예시는 기능 설명을 위해 직접 그린 그림이며, 네이버 클라우드 콘솔의 화면이나 이미지를 사용하지 않았습니다.

2. 하는 일과 하지 않는 일

  • 하는 일: 콘솔 페이지의 화면 요소를 읽고, 탭 제목·아이콘을 바꾸고, 서버 접속 콘솔 위에 버튼을 추가하고, 사용자 대신 "연장" 버튼을 누릅니다.
  • 하지 않는 일: 로그인·인증을 대신하거나 우회하지 않습니다. 전체 연결 시간 20분 한도를 우회하거나 늘리지 않습니다. 콘솔 서버에 직접 요청을 보내지 않습니다.

3. 사용자 책임

  • 자동 연장은 자리를 비운 사이에도 서버 접속 콘솔 세션을 최대 20분까지 유지합니다. 소속 조직의 보안 정책에 어긋나지 않는지 확인한 뒤 사용하세요. 필요 없으면 끄시면 됩니다.
  • 회사·기관의 보안 정책이나 NAVER Cloud의 이용약관에 따라 자동화 도구 사용이 제한될 수 있습니다. 이를 확인하고 지킬 책임은 사용자에게 있습니다.
  • 콘솔 화면 위의 시간 표시와 20분 종료 예고는 참고용입니다. 네트워크 상태나 브라우저 상태에 따라 실제 종료 시점과 다를 수 있으니, 중요한 작업은 미리 저장하세요.

4. 보증의 부인과 책임 제한

  • 이 확장 프로그램은 "있는 그대로" 제공되며, 특정 목적에의 적합성, 정확성, 무중단·무오류에 대한 어떠한 보증도 하지 않습니다.
  • 네이버 클라우드 콘솔의 화면 구조나 동작이 바뀌면 일부 또는 모든 기능이 예고 없이 동작하지 않을 수 있습니다.
  • 법이 허용하는 범위에서, 이 확장 프로그램의 사용 또는 사용 불능으로 인한 세션 종료, 작업 손실, 데이터 손실, 서비스 이용 제한 등 어떠한 손해에 대해서도 개발자는 책임을 지지 않습니다.

5. 개인정보

데이터 처리에 관한 내용은 개인정보처리방침을 확인해 주세요. 요약하면 어떤 데이터도 수집하거나 외부로 전송하지 않습니다.

6. 소스 코드와 라이선스

소스 코드는 GitHub 저장소에서 확인할 수 있습니다. 코드는 MIT 라이선스로 공개되며, 사용·복제·수정·배포 조건은 저장소의 LICENSE 파일을 따릅니다. MIT 라이선스는 이 프로그램의 코드에만 적용되며, NAVER·Ncloud 등의 이름, 로고, 상표에 대한 어떠한 권리도 부여하지 않습니다.

7. 변경

이 안내는 필요에 따라 바뀔 수 있으며, 변경되면 위의 시행일을 갱신합니다. 문의는 GitHub 이슈로 남겨 주세요.
