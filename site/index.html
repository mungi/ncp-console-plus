주요 기능

콘솔을 쓰면서 불편했던 부분을 작은 기능으로 덜어 줍니다. 모든 기능은 켜고 끌 수 있습니다.

탭 이름을 서비스명으로

탭이 많아도 어느 화면인지 바로 구분됩니다.

  • 제목: 메뉴명 - 서비스명
  • 선택한 리전 아이콘을 탭 아이콘 자리에 표시
  • 긴 서비스명은 축약 (예: CDB PostgreSQL)
  • 한 번 방문한 화면은 제목을 기억해 깜빡임 최소화
  • 한국
  • 미국서부

서버 접속 콘솔 전체화면

작은 모달 창 대신 콘솔 화면을 크게 볼 수 있습니다. 버튼은 두 가지입니다.

  • 모니터 전체화면: 화면 전체를 콘솔로 채움
  • 브라우저 창 전체화면: 탭과 주소창은 유지
  • 전체화면 중에도 종료 버튼과 알림 표시

접속 시간 자동 연장

5분 세션이 끝나기 전에 "연장"을 대신 눌러 줍니다. 전체 연결 시간 최대 20분은 콘솔 정책이라 늘릴 수 없습니다.

  • 백그라운드 탭에서도 실제 경과 시간 기준으로 동작
  • 콘솔 위 스위치로 즉시 켜기/끄기

20분 종료 예고

강제 종료 2분 전부터 남은 시간을 알려 줍니다. 마지막 1분에는 빨간색으로 바뀝니다. 종 아이콘으로 켜고 끌 수 있습니다.

기능별 켜고 끄기

확장 아이콘을 누르면 "탭 이름 변경"과 "서버 접속 콘솔 추가 기능"을 각각 끌 수 있습니다. 끄면 콘솔 원래 모습으로 돌아갑니다.

데이터 수집 없음

외부 서버로 아무것도 보내지 않습니다. 설정값과 탭 제목 기록만 내 브라우저에 저장합니다. 개인정보처리방침

  • 서버 접속 콘솔(VNC)을 자주 쓰는 분
  • 5분마다 "연장"을 누르는 게 번거로운 분

설치 방법

Chrome 웹 스토어 등록은 준비 중입니다. 그동안은 아래처럼 직접 설치할 수 있습니다.

  1. GitHub 저장소에서 Code → Download ZIP으로 내려받아 압축을 풉니다.

  2. Chrome 주소창에 chrome://extensions를 입력하고, 오른쪽 위 개발자 모드를 켭니다.

  3. 압축해제된 확장 프로그램을 로드합니다를 누르고, 압축을 푼 폴더 안의 extention 폴더(manifest.json이 있는 폴더)를 선택합니다.

  4. 이미 열려 있던 콘솔 탭은 새로고침합니다. 이제 탭 이름이 바뀌고, 서버 접속 콘솔을 열면 버튼이 나타납니다.

자주 묻는 질문

더 궁금한 점은 지원 페이지를 확인해 주세요.

전체 연결 시간 20분 제한을 늘릴 수 있나요?

아니요. 20분은 네이버 클라우드 콘솔이 정한 한도입니다. 콘솔 화면의 타이머와 서버가 모두 이 한도를 적용하므로 이 확장으로 늘릴 수 없고, 자동 연장은 20분 안에서 5분 세션이 끊기지 않게만 해 줍니다.

자동 연장을 써도 되나요? 보안 정책에 어긋나지 않을까요?

자리를 비운 사이에도 콘솔 세션이 최대 20분까지 유지됩니다. 소속 조직의 보안 정책(유휴 세션 정책 등)을 확인하신 뒤 사용해 주세요. 콘솔 위 스위치나 확장 아이콘 팝업에서 언제든 끌 수 있습니다.

전체화면 버튼이 보이지 않아요.
  • 서버 목록에서 "서버 접속 콘솔" 창이 열려 있어야 합니다. 확장은 그 창의 "연장" 버튼 옆에 버튼을 넣습니다.
  • 확장 아이콘을 눌러 "서버 접속 콘솔 추가 기능"이 켜져 있는지 확인해 주세요.
  • 설치 직후라면 콘솔 탭을 새로고침해 주세요.
  • 금융·공공 클라우드나 Neuro처럼 서버 접속 콘솔 주소가 다른 환경에서는 버튼이 나타나지 않을 수 있습니다. 이슈로 알려 주세요.
탭 이름이 처음에는 잠깐 다르게 보였다가 바뀌어요.

콘솔이 서비스명 정보를 페이지 끝부분에서 늦게 보내 주기 때문에, 처음 방문하는 화면에서는 콘솔 기본 제목이 잠깐 보였다가 한 번 바뀔 수 있습니다. 한 번 방문한 화면은 제목을 기억해 두었다가 바로 표시합니다.

다른 "탭 이름 변경" 확장 프로그램과 같이 써도 되나요?

서로 제목을 덮어쓰기 때문에 함께 쓰지 않는 것을 권합니다. 이 확장은 다른 확장이 제목을 계속 바꾸면 잠시 제목 변경을 멈춥니다.

개인정보나 콘솔 내용을 수집하나요?

아니요. 외부 서버로 데이터를 보내지 않고 분석·추적 도구도 없습니다. 자세한 내용은 개인정보처리방침을 확인해 주세요.

네이버 클라우드(NAVER Cloud)에서 만든 공식 확장 프로그램인가요?

아닙니다. 개인이 만든 비공식 확장 프로그램이며 NAVER Cloud와 제휴·후원 관계가 없습니다. 이용 안내를 확인해 주세요.
