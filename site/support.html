먼저 확인해 보세요

탭 이름이나 리전 아이콘이 바뀌지 않아요

  • 확장 아이콘을 눌러 "탭 이름을 서비스명으로 변경"이 켜져 있는지 확인해 주세요.
  • 설치·업데이트 직후에는 콘솔 탭을 새로고침해야 합니다.
  • 다른 탭 이름 변경 확장 프로그램이 설치되어 있다면 끄거나 제거해 주세요. 서로 제목을 덮어씁니다.
  • 주소가 https://*.ncloud.com, console.fin-ncloud.com, console.gov-ncloud.com 중 하나인지 확인해 주세요.

서버 접속 콘솔의 전체화면 버튼·자동연장 스위치가 안 보여요

  • 서버 접속 콘솔 창이 열려 있고 "연장" 버튼이 보이는 상태여야 합니다.
  • 확장 아이콘의 "서버 접속 콘솔 추가 기능"이 켜져 있는지 확인해 주세요. 끄면 추가 UI가 모두 사라지고 원래 "연장" 버튼만 남습니다.
  • 콘솔 탭을 새로고침해 주세요.
  • 금융·공공 클라우드나 Neuro처럼 서버 접속 콘솔 화면 주소가 다른 환경에서는 동작하지 않을 수 있습니다. 아래 방법으로 제보해 주세요.

전체화면이 풀리지 않아요

  • 모니터 전체화면: 같은 버튼을 다시 누르거나 Esc를 누르세요.
  • 브라우저 창 전체화면: 오른쪽 위의 반투명 종료 버튼을 누르세요. 콘솔 화면을 클릭한 뒤에는 Esc가 원격 서버로 전달되어 창 전체화면이 풀리지 않을 수 있습니다.

자동 연장이 되지 않아요

  • 콘솔 위 "자동연장" 스위치와 "서버 접속 콘솔 추가 기능" 토글이 모두 켜져 있어야 합니다.
  • 전체 연결 시간이 20분에 도달하면 콘솔이 세션을 닫으므로 더 이상 연장되지 않습니다. 이는 콘솔의 정책입니다.
  • 연장은 남은 시간이 1분 이하일 때, 또는 마지막 연장 뒤 실제 시간으로 3분 45초가 지났을 때 실행됩니다.

버그 제보·문의

GitHub 이슈에 남겨 주세요. 아래 내용을 함께 알려 주시면 원인을 빨리 찾을 수 있습니다.

  • 확장 프로그램 버전 (확장 아이콘 팝업 오른쪽 위의 v0.0.0 형식)
  • Chrome 버전과 운영체제
  • 사용한 콘솔: 민간 / 금융 / 공공 / Neuro 등, 그리고 주소의 호스트 부분(예: console.ncloud.com)
  • 어떤 화면에서 무엇을 했고, 어떻게 보였는지 (기대한 동작과 실제 동작)
  • 가능하면 스크린샷. 계정 정보, 서버 이름, IP 주소 등 민감한 정보는 가려 주세요.

비밀번호, 세션 키, 토큰 같은 정보는 이슈에 절대 적지 마세요. 필요하지 않습니다.

로그 확인 방법

문제를 분석하려면 확장 프로그램의 로그가 도움이 됩니다.

  1. 콘솔 탭에서 F12를 눌러 개발자 도구를 엽니다.
  2. Console 탭에서 로그 수준에 Verbose가 포함되도록 설정합니다.
  3. 필터에 ncloud-ext를 입력하면 이 확장 프로그램의 로그만 보입니다.
  4. 페이지를 새로고침한 뒤 나오는 로그를 이슈에 붙여 주세요. 탭 제목이 바뀐 시점과 이유가 기록됩니다.

업데이트

새 버전과 변경 내용은 GitHub 릴리스에서 확인할 수 있습니다. 직접 설치한 경우에는 새 버전을 내려받아 같은 폴더를 덮어쓰고 chrome://extensions에서 확장 프로그램을 새로고침해 주세요.
